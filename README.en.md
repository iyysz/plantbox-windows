# Dafeng Smart Warehouse (达丰智慧仓储)

3D warehouse operations desktop demo. See the Chinese [README.md](README.md) for full instructions.

```sh
npm install
npm run dev          # browser
npm run electron:build   # Windows portable exe → release/
```

Based on [workbzw/plantbox](https://github.com/workbzw/plantbox); rebranded UI with GitHub/docs links removed. MIT.
