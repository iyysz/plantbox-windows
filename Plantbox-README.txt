Plantbox 桌面版（Windows x64）

文件：Plantbox-portable.exe（约 92 MB，免安装便携版）

用法：
1. 把 Plantbox-portable.exe 拷到任意文件夹
2. 双击运行
3. 会打开本地窗口，自动进入中文首页（/#/zh）
4. 无需联网、无需浏览器、不依赖 Vercel

说明：
- 首次运行可能被 Windows SmartScreen 拦截（未签名软件常见）。点「更多信息」→「仍要运行」。
- 杀毒软件偶发误报，可加入白名单。
- 数据仅在本机内存演示，刷新/关闭后重置。
- 需要较新的显卡驱动以流畅运行 WebGL/3D。

构建来源：https://github.com/workbzw/plantbox
